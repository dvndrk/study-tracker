dvndrk Study Tracker

A customizable, offline-first study tracker built with Node.js, Express, HTML, CSS and JavaScript.

Features-
- Customizable application name and subtitle
- User-defined subjects, chapters and study parameters
- Chapter completion tracking
- Revision tracking
- Local JSON-based data storage
- Runs locally on your computer

Requirements - Node.js version required by the current project.

Installation-
1. Clone the repository.
2. Run npm install.
3. Run npm start.
4. Open http://localhost:3000.

Data and privacy - Study data is stored locally in data/subjects.json. Keep personal study data out of public Git commits.

Development status - hobby project to learn building so no status.
